# Two Skies

A 3D co-op game for two. One plays the Sun, the other the Moon. Walk, jump, carry, throw, punch, high five and solve puzzles together across fifteen levels.

Play: https://ayemin05.github.io/two-skies/

- Single player (control both) or play together on two phones
- English and Burmese (မြန်မာ)
